    查看本工具采用的判定规则（摘自 RECIST 1.1）
    1. 淋巴结：淋巴结按短轴测量；短径 ≥15 mm 的淋巴结才可作为靶病灶并计入直径总和；短径 10–<15 mm 属非靶病灶；<10 mm 视为正常。
    2. CR（靶病灶）：所有非淋巴结靶病灶须完全消失（0 mm）；所有病理性淋巴结（无论靶病灶或非靶病灶）短径必须缩小至 < 10 mm —— 淋巴结不必完全消失，短径 <10 mm 即视为正常（RECIST 1.1 §3.3）。
    3. PR（靶病灶）：靶病灶直径之和比基线减少至少 30%。
    4. PD（靶病灶）：以研究过程中所有靶病灶直径总和的最小值为参照，增加至少 20%（基线为最小值时以基线为参照），且绝对值增加至少 5 mm；出现新病灶也视为 PD。
    5. SD（靶病灶）：缩小未达 PR、增加未达 PD，介于两者之间。
    6. 非靶病灶：CR = 全部消失且标志物正常、淋巴结短径<10mm；非CR/非PD = 持续存在和/或标志物仍高于正常；PD = 明确进展（新病灶也视为 PD）。
    7. 总缓解组合：靶 PD / 非靶 PD / 有新病灶 → 总 PD；靶 CR + 非靶 CR → CR；靶 CR + 非靶非CR非PD（或不能评估）→ PR；靶 PR + 非靶非进展 → PR；靶 SD + 非靶非进展 → SD；无靶病灶时按非靶病灶单独判定（CR / 非CR非PD / NE）。
    8. 最新肿评结果：取最近一次随访（按随访日期/录入顺序的最后一条）的总缓解作为该病例当前的疗效结论，并标注该次随访的时间点与首次 PD 的时间点。
    9. 病灶匹配：随访病灶按名称与基线匹配；基线有而随访未记录的病灶记 0 mm（视为消失）；随访出现基线没有且 >0 mm 的病灶自动计为新发病灶 → PD。
    10. ORR / DCR：ORR =（CR + PR）/ 可评估例数；DCR =（CR + PR + SD）/ 可评估例数。可评估例数为有随访结果且最新肿评结果非 NE 的病例。
